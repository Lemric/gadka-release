# Gadka — wydania

Tu publikowane są pliki instalacyjne aplikacji Gadka (macOS, Linux, Windows), instalator serwera oraz paczki aktualizacji.

- Pobieranie i opis: https://gadka.lemric.com/pobierz
- Wszystkie wersje: zakładka [Releases](https://github.com/Lemric/gadka-release/releases)

Każde wydanie zawiera plik `…-SHA256SUMS` z sumami kontrolnymi. Aplikacje desktopowe aktualizują się same przez podpisany kanał aktualizacji.
